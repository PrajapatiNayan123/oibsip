# OIBSIP Web Development — Level 1 Task 2
## Personal Portfolio

A responsive personal portfolio website built with HTML5 and CSS3, with a small JavaScript enhancement for the mobile navigation menu.

### Features
- Name, role and avatar placeholder
- About Me section
- Skills section
- Two project cards
- Contact section with email, LinkedIn and GitHub
- Smooth-scroll navigation
- Responsive desktop/tablet/mobile layout
- Consistent dark visual branding

### Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript (mobile navigation enhancement)
- Google Fonts (Inter)

### Folder
`OIBSIP/WebDev-L1-PersonalPortfolio/`

### How to Run
Open `index.html` in a browser.
