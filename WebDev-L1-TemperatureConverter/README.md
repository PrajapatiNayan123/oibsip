# OIBSIP Web Development — Level 1 Task 3
## Temperature Converter Website

A responsive temperature conversion utility built with HTML5, CSS3 and Vanilla JavaScript.

### Features
- Celsius, Fahrenheit and Kelvin units
- Numeric input validation
- Convert button and clear button
- Accurate Celsius/Fahrenheit/Kelvin conversion
- Absolute-zero validation
- Clear result display
- Responsive layout for mobile and desktop
- No external JavaScript libraries

### Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

### Folder
`OIBSIP/WebDev-L1-TemperatureConverter/`

### How to Run
Open `index.html` in a browser.
