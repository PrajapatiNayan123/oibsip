# NovaFlow Landing Page — OIBSIP Web Development Level 1

A polished, responsive static landing page created for the **Oasis Infobyte Internship Program — Web Development & Designing, Level 1, Task 1: Landing Page**.

## Task Requirements Covered

According to the internship task list, the landing page should include a sticky/fixed navigation bar with at least three links, a hero section with headline/subheadline/CTA, at least two content sections, a footer, a consistent palette, responsive layout, no element overlap, and readable typography. This project implements all of these requirements.

## Tech Stack

- HTML5
- CSS3
- CSS Flexbox & Grid
- Google Fonts (DM Sans + Space Grotesk)
- No JavaScript required

## Features

- Sticky responsive navigation
- Hero section with primary and secondary CTAs
- Product dashboard visual built entirely with HTML/CSS
- Features section with three feature cards
- About/story section
- Testimonial/review section
- Final CTA section
- Responsive mobile, tablet, and desktop layouts
- Semantic HTML structure
- Accessible navigation labels and descriptive page metadata
- Clean component-like CSS organization

## How to Run

1. Download or clone the repository.
2. Open `index.html` in any modern browser.
3. For local development, use VS Code + Live Server if available.

## Customization

Change the brand name, copy, colors, CTA email, and feature text directly in `index.html` and `style.css`.
